1. CREAR Y ACTIVAR EL ENTORNO VIRTUAL
--------------------------------------

py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

Si PowerShell bloquea la activacion:

Set-ExecutionPolicy -Scope Process Bypass
.\.venv\Scripts\Activate.ps1


2. INSTALAR EL PROYECTO
-----------------------

python -m pip install -e ".[test]"

Comprobar la version de Python:

python --version

Comprobar que pytest esta disponible:

python -m pytest --version


3. EJECUTAR TODAS LAS PRUEBAS
-----------------------------

python -m pytest -q

Ejecutar las pruebas con mayor detalle:

python -m pytest -v

Ejecutar un archivo especifico de pruebas:

python -m pytest tests/test_dat01.py -v


4. COMPROBAR LA SINTAXIS
------------------------

python -m compileall -q src tests

-------------------------------

8. CONSULTAR EL HISTORIAL
-------------------------

python -m tfg_demografia history --db data/db/imports.sqlite

Consultar el historial en JSON:

python -m tfg_demografia history --db data/db/imports.sqlite --json


9. PROBAR UN TXT DIRECTAMENTE
-----------------------------

El lector acepta un TXT directo. Use un archivo sintetico de prueba con registros
de la longitud definida por su esquema. Ejemplo para nacimientos:

python -m tfg_demografia read --source "ruta\a\archivo_sintetico.txt" --dataset nacimientos --db data/db/imports.sqlite


10. GENERAR EVIDENCIAS JSON
---------------------------

python -m tfg_demografia read --source "data/raw/tse/nacimientos/movimientos/2026/08_agosto/01_06/nac_agosto2026_01_06.zip" --dataset nacimientos --db data/db/imports.sqlite --json | Out-File -Encoding utf8 docs/evidencias/ejecucion_nacimientos.txt

python -m tfg_demografia read --source "data/raw/tse/matrimonios/movimientos/2026/08_agosto/01_06/mat_agosto2026_01_06.zip" --dataset matrimonios --db data/db/imports.sqlite --json | Out-File -Encoding utf8 docs/evidencias/ejecucion_matrimonios.txt
